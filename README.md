# Customer Segmentation Project

## Project Overview
This project uses machine learning to segment customers based on their
annual income and spending behavior. K-Means clustering is used to
identify meaningful customer groups.

## Tools & Technologies
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Power BI
- DAX

## Dataset
The dataset contains 1,000 customers with information about:
- Customer ID
- Gender
- Age
- Annual Income
- Spending Score

## Data Cleaning
Missing values were handled using:
- Mode for Gender
- Median for Age
- Median for Annual Income
- Median for Spending Score

## Machine Learning
K-Means clustering was used to create 5 customer segments.

## Customer Segments
- Regular Customers
- High Income - Low Spending
- Potential Customers
- Young High-Spending Customers
- High Income - At-Risk Customers

## Power BI Dashboard
The dashboard includes:
- Total Customers
- Average Spending Score
- Average Annual Income
- Customer Segment Distribution
- Income vs Spending Analysis

## Key Insights
- Potential Customers form the largest segment.
- Young customers show relatively high spending behavior.
- High-income, low-spending customers are potential targets for marketing campaigns.
- High-income, at-risk customers may benefit from retention strategies.
